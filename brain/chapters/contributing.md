# Contributing

The brain is files in Petals' repo, and the repo is its only source. It improves by pull request, reviewed before anything changes for anyone.

1. **When the person says a chapter missed something,** or a recipe worked for a new system, draft the change: the file, and a line on what went wrong or what worked.
2. **Open the pull request** on the repo: fork, branch, commit, open, with `gh` or GitHub's website.
3. **If the person has no GitHub,** help them make an account; they sign up themselves, and you never handle their password.

The repo isn't public yet. Until it is, put the drafted file in the conversation's notes (`add_note`) so it isn't lost, and tell the person it waits for the repo to open.

# Connecting

Getting a person and their agent onto Petals.

## When to use which chapter

| Chapter | Use it for |
|---|---|
| `setup` | a person setting up Petals from any chatbot, step by step: a wallet, signing in, credit, a first conversation |
| `connect-claude-code` | connecting Claude Code to Petals, in a terminal or under Code in the Claude desktop app, and keeping it for next time |
| `connect-codex` | connecting Codex to Petals, in a terminal, and keeping it for next time |
| `connect-hermes` | connecting Hermes, Nous Research's agent, to Petals, in a terminal or over ACP, and keeping it for next time |
| `connect-cloud` | connecting an app that runs in the cloud, or takes a remote MCP server's URL, to Petals as a connector: the Claude app, ChatGPT, Cursor |

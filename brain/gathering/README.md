# Gathering

What a thing is, and how to read something new.

## When to use which chapter

| Chapter | Use it for |
|---|---|
| `start-from-an-address` | any address or account, when nothing is known about it yet |
| `what-kind-of-thing-it-is` | describing an account or network's technical form, roles and declared organisation type |
| `a-new-system` | a contract or system Petals has no recipe for yet |
| `open-source-leads` | public traces that might say what an address did, as directions only |
| `open-calls` | who is paying for work right now: open RFPs, grants programs, bounties, hackathons and open votes |

# Chain and token logos

The branded SVGs from web3icons (`@web3icons/core` 4.0.59, MIT, https://github.com/0xa3k5/web3icons), one file per
1Click chain id (`chains/<id>.svg`) and per token symbol (`tokens/<SYMBOL>.svg`), for paying with another token.
A coin that is its own chain's (MON, BERA, OKB, XPL) is drawn as the chain. `lib/token-icons.ts` lists what is
here; anything else is drawn as its first letter.

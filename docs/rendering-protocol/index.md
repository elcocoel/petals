A view is the person's glasses: it joins pieces of data to dimensions. The current format is [view/v2](/docs/data-protocol/schemas/view-v2). The person can change those choices without changing the data.

Read the view contract below for the dimensions and their kinds. It includes historical implementation notes; those notes describe their dated stage, not a guarantee about today's renderer.
